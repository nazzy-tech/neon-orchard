# Neon Orchard

A small, static after-dark arcade game for start.ng. Move the basket with the arrow keys or by dragging on touch screens. Collect ripe fruit and avoid wilted fruit before the 30-second round ends.

The game uses start.ng's connect frame for player identity, character display, shared scores, and its leaderboard. It also works as a local static page with a local best score.

## Files

- `index.html` — complete playable game
- `startng.json` — shared leaderboard columns
- `cover.png` — start.ng game card art
- `icon.svg` — browser tab icon
